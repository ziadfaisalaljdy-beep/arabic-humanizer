# أنسَنة — Arabic Humanizer

**أول مهارة عربية لتنقية النصوص من بصمات الذكاء الاصطناعي.**

## لماذا؟
أدوات الأنسنة الإنجليزية (مثل blader/humanizer) لا تفهم العربية،
ونصوص الذكاء الاصطناعي العربية لها بصماتها الخاصة:
«علاوة على ذلك»، «يُعدّ»، «في الختام لا يسعنا إلا...»، والمديح المبالغ فيه.

## ما هذا؟
ملف `SKILL.md` يحتوي 14 قاعدة + أمثلة (قبل/بعد) تعلّم أي وكيل ذكاء اصطناعي
إعادة صياغة النص العربي ليبدو بشرياً طبيعياً.

## كيف أستخدمه؟
**طريقة 1:** انسخ محتوى `SKILL.md` إلى مجلد المهارات لدى وكيلك
(متوافق مع معيار Agent Skills).
**طريقة 2 (الأسهل):** الصق محتوى SKILL.md مرة واحدة لأي ذكاء اصطناعي وقل له:
«طبّق قواعد أنسَنة على هذا النص: ...»

## ساهم معنا
عندك قاعدة أو مثال؟ افتح Issue أو Pull Request — المشروع مفتوح للجميع.
